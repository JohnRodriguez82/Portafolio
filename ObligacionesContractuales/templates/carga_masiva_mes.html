Carga Masiva de Evidencias por Mes

Flujo de trabajo en 3 pasos:
  1. Seleccione el mes y año y descargue la plantilla Excel con las obligaciones del contrato.
  2. Complete para cada obligación: Anuncio/Contexto, Fecha y Nombre de imagen. Puede agregar varias filas por obligación.
  3. Suba el Excel + las imágenes juntas. El sistema creará los reportes y evidencias automáticamente.
Paso 1: Descargar Plantilla del Mes
La plantilla incluye:
  • Todas las obligaciones del contrato con número y descripción
  • Columnas para completar: Anuncio, Fecha, Nombre Imagen
  • Puede duplicar filas para múltiples evidencias por obligación
Consejos:
  • Use nombres de imagen cortos y sin espacios (ej: obl3_act1.jpg)
  • La fecha debe pertenecer al mes que seleccionó
  • Si una obligación no tiene evidencias, simplemente elimine su fila

Guía Detallada y Notas Importantes
Reglas del Excel
  • No modifique los encabezados ni las columnas A y B
  • Inserte tantas filas como evidencias necesite por obligación
  • Elimine las filas de obligaciones sin evidencias este mes
  • Fecha: YYYY-MM-DD o DD/MM/YYYY
  • Nombre imagen: con extensión exacta (ej: foto.jpg)
Reglas de las Imágenes
  • El nombre en Excel debe ser idéntico al archivo
  • Puede subir todas las imágenes en un solo lote
  • Tamaño máximo por archivo: 16 MB
  • Si omite el nombre de imagen, se crea la actividad sin evidencia visual
  • Cada imagen se usa una sola vez; no se reutiliza
Procesamiento Automático
  • Crea automáticamente los reportes mensuales por obligación
  • Si el reporte ya existe, agrega las nuevas evidencias
  • Con API key Gemini: analiza cada imagen con IA
  • Genera párrafos descriptivos automáticos
  • Enumera actividades consecutivamente por reporte
Importante: Este proceso puede tardar varios minutos si carga muchas imágenes y tiene activado el análisis con IA (Gemini). No cierre la página hasta ver el mensaje de confirmación.
